## À propos

Je suis développeur PHP / Symfony en reconversion professionnelle, basé en Corse.

J’ai commencé à coder par curiosité, puis j’ai créé mon premier site en 2020. Depuis 2023, je développe sérieusement des sites et applications web pour des projets concrets : outils de gestion, sites vitrines avec back-office, e-commerce, automatisations métier et intégrations d’API.

Aujourd’hui, je recherche mon premier CDI en développement web afin de rejoindre une équipe, progresser sur des projets plus ambitieux et continuer à monter en compétences sur Symfony, l’architecture applicative et les bonnes pratiques de développement.

## Projets principaux

### Portfolio Symfony 8

Application Symfony 8 pour présenter mon profil développeur, avec une vitrine publique, un formulaire de contact et une interface d’administration sécurisée.

Fonctionnalités principales :

- Page portfolio dynamique
- Gestion des projets depuis un back-office
- Gestion du profil, des compétences, du CV et des images
- Formulaire de contact avec Symfony Mailer
- Doctrine ORM, migrations, Twig et AssetMapper

Repo : [portfolio](https://github.com/buzzer93/portfolio)  
Site : [nicolas-rodriguez.fr](https://nicolas-rodriguez.fr/)

---

### KDOS-GRAPHIE

Site vitrine + e-commerce pour des produits graphiques personnalisables.

Fonctionnalités principales :

- Catalogue produits
- Panier
- Commande sans compte client
- Personnalisation avec texte et image
- Interface d’administration
- Workflow de validation de commande
- Paiement Stripe
- Notifications email

Repo : [kdos-graphie.fr](https://github.com/buzzer93/kdos-graphie.fr)

---

### Gestion Trièves Connect

Application web créée pour simplifier la gestion d’inventaire d’une boutique informatique.

Fonctionnalités principales :

- Gestion des produits et services
- Inventaire avec lecteur de codes-barres
- Génération et impression d’étiquettes
- Export Excel avec PhpSpreadsheet
- Version de démonstration avec données réinitialisées automatiquement

Repo : [gestion-trievesconnect-demo](https://github.com/buzzer93/gestion-trievesconnect-demo)  
Démo : [gestion-trieves.nicolas-rodriguez.fr](https://gestion-trieves.nicolas-rodriguez.fr/)
